## 高信息运行时验证 / High-information runtime checks

- 最终 `dist/rust/status` 模块直接加载，不在测试里重新编写组合入口：公开读取、bootstrap、管理 HTTP 隔离及单一关联身份。 / Load the final module graph directly, without rebuilding a test compositor: public reads, bootstrap, admin HTTP isolation and one correlation identity.
- 命名 `AdminRpc` 的 27 项能力与默认入口隔离；实际 Access/角色、CSRF、来源和正文限制。 / Isolate 27 named administrative capabilities from the default entry; actual Access/roles, CSRF, origin and body limits.
- 真实 D1 迁移、并发幂等、过期版本拒绝、后置失败全事务回滚、服务和组件候选状态一起提交。 / Real D1 migrations, concurrent idempotency, stale revision rejection, full rollback after later failure and atomic candidate service/component state.
- 最终模块的真实 Queue trigger → 通知 HTTP → DLQ；错误队列别名不会误分流。 / Actual final-module Queue trigger → notification HTTP → DLQ; queue aliases do not cross-route messages.
- 最终模块的真实 ScheduledEvent；产物清理故障不阻断调度，bootstrap 不推进业务。 / Actual final-module ScheduledEvent; cleanup failures do not block scheduling and bootstrap does not advance business state.
- Rust SDK 保持重试事件字节、身份与追踪稳定，每次尝试重新取凭据，限制认证、请求和回执读取时间。 / Rust SDK retries preserve bytes, identity and trace, refresh credentials per attempt and bound authorization, request and receipt time.

## 平台成本与证据边界 / Platform cost and evidence limits

本次 Wrangler 报告的 gzip 上传体积约为 status 1480 KiB、ops 492 KiB、probe 294 KiB；这不是冷启动、延迟或吞吐基准。两个 status Wasm 模块的独立初始化和内存成本仍需生产负载测量。 / Wrangler reports approximately 1480 KiB, 492 KiB and 294 KiB gzip uploads for status, ops and probe. These are not cold-start, latency or throughput benchmarks. The two status Wasm modules' initialization and memory costs still require production-load measurement.

R2 尚未开通，未执行应用云部署、真实地域 placement、供应商遥测目的地及云端 S3 验收。TCP 成功连接/关闭、超时后的远端资源释放不在本地已验证范围内。诊断 SDK 是有界内存尽力投递，不是持久队列，也不保证零丢失。 / R2 is not provisioned; application deployment, actual geographic placement, vendor telemetry destinations and cloud S3 remain unverified. TCP connection success/closure and remote resource release after timeout are outside the verified local scope. The diagnostic SDK is bounded in-memory best-effort delivery, not a durable or lossless queue.
